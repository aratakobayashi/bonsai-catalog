盆栽は、完成したものを買うだけでなく、園芸店やホームセンターで売られている苗木から自分で作ることもできます。盆栽の世界では、こうした盆栽の材料になる樹を「素材」と呼びます。

苗木は数百円〜数千円で手に入るものが多く、自分で枝を選び、鉢を選び、形を決めていく楽しさがあります。一方で、盆栽らしい姿になるまでには、数年かけて手入れを重ねる必要があります。最初の1年で完成させようとせず、**樹を弱らせずに少しずつ形に近づける** ことを目標にします。

ここでは、苗木の選び方から、最初の作業の順番、植え付けたあとの1年の流れまでを説明します。

## 盆栽に向く苗木の選び方

![盆栽に向く苗木の見どころ。根元が太く四方に根が張る、幹が根元から上に向かって細くなる、下のほうにも枝がある、葉が詰まって元気](/images/articles/diagrams/bonsai-from-nursery-stock-choose.svg)
*図：苗木を選ぶときに見る4つのところ*

同じ値段の苗木でも、盆栽に向くものと向かないものがあります。売り場では、葉や花の見た目より、**根元と幹と枝の付き方** を見て選びます。

| 見るところ | 向いている苗木 | 理由 |
|---|---|---|
| 根元（根張り） | 根が四方に広がり、地面をつかむように見える | 根張りは盆栽の見どころの1つで、あとから作るのは時間がかかる |
| 幹の太り方 | 根元が太く、上に向かって細くなる | 小さな鉢でも大木らしく見える |
| 枝の付き方 | 下のほうにも枝がある | 盆栽は低い位置の枝を生かすことが多い。下に枝がないと形を作りにくい |
| 元気さ | 葉が詰まり、色つやがよい。害虫や病気の跡がない | 最初の作業に耐えられる体力がある |

背が高くまっすぐなだけの苗木より、低い位置で枝分かれし、幹に少し動きのあるもののほうが、盆栽らしい形を作りやすくなります。

### 始めやすい樹種

初めて苗木から作るなら、丈夫で芽吹きのよい樹種が向いています。

| 樹種 | 楽しみ | 始めやすい理由 |
|---|---|---|
| 真柏（しんぱく） | 一年中緑の葉と、幹の動き | 丈夫で、針金で形を作りやすい |
| 五葉松（ごようまつ） | 短い葉と、引き締まった姿 | 生長がゆっくりで、形が崩れにくい |
| もみじ | 新緑と紅葉 | 芽吹きがよく、枝を切っても新しい枝が出やすい |
| 長寿梅（ちょうじゅばい） | 小さな花を長く咲かせる | 丈夫で、小さな鉢でも育てやすい |
| ケヤキ・ニレケヤキ | 細かな枝ぶり | 芽吹きがよく、細かい枝を作りやすい |

樹種ごとの育てやすさや見頃は、[盆栽初心者に向く樹種の選び方](/guides/beginner-tree-species-guide)でも比べています。

## 作業に向く時期

苗木を盆栽鉢に植え、枝を整理する最初の作業は、根と枝の両方を切る大きな作業です。多くの樹種では、**芽が動き出す直前の早春（2月下旬〜3月ごろ）** が向いています。冬の休みから目覚めるところで、切った根や枝から回復しやすいためです。

- **もみじ・ケヤキなどの落葉樹**：葉が出る前の2月下旬〜3月。枝ぶりが見えて、切る枝を決めやすい時期です。
- **真柏・五葉松などの松柏類**：3〜4月ごろ。新芽が伸び出す前が目安です。
- **長寿梅などの花もの**：花の時期によって変わります。花が終わってから作業すると、花を楽しんでから形を整えられます。

真夏と真冬は、根を切ると樹が弱りやすいので避けます。時期を外して苗木を買ったときは、植え付けや大きな剪定は適期まで待ち、それまではポットのまま育てます。

## 用意するもの

| 用意するもの | 目安 |
|---|---|
| 盆栽鉢 | 苗木の根の量に合う大きさ。最初は浅すぎない鉢が安心 |
| 用土 | 赤玉土（小粒）を中心にした盆栽用の土 |
| 鉢底ネットと針金 | 鉢底の穴をふさぎ、樹を鉢に固定する |
| 剪定ばさみ・又枝切り | 枝を切る道具。太い枝は又枝切りで |
| 針金（アルミ線） | 枝の向きを整えるとき。最初の年は使わないことも多い |
| 竹串・土入れ | 根の間に土を行き渡らせる |

鉢の大きさや土の配合は、[鉢・土・道具をそろえる](/soroeru)で、樹の大きさから目安を調べられます。道具の選び方は[盆栽ばさみの選び方](/guides/bonsai-scissors-guide)にまとめています。

## 作り方の手順

![苗木から盆栽を作る5つの手順。正面を決める、残す枝を決めて切る、根を整える、鉢に植えて固定する、水をやって休ませる](/images/articles/diagrams/bonsai-from-nursery-stock-steps.svg)
*図：最初の作業の流れ*

1. **正面を決める**：苗木をいろいろな向きから眺め、根張りがよく見え、幹の動きがきれいに見える向きを「正面」にします。幹が正面から見てやや手前に傾いているくらいが、盆栽らしく見えます。
2. **残す枝を決めて切る**：正面から見て、左右と後ろにバランスよく枝が出るように、残す枝を決めます。真正面に飛び出す枝、同じ高さから何本も出る枝、内側に向かう枝など、形を乱す枝（忌み枝）を根元から切ります。一度に切りすぎず、迷った枝は残しておきます。
3. **根を整える**：ポットから抜き、根鉢の外側と底の土を竹串でほぐして落とします。太く長い根や傷んだ根を切り、鉢に収まる大きさにします。根を切る量は、全体の3分の1ほどまでにとどめます。
4. **鉢に植えて固定する**：鉢底にネットを付け、固定用の針金を通しておきます。薄く土を敷いて樹を置き、正面と高さを確かめてから針金で固定します。土を入れたら、竹串で軽くつついて根の間に行き渡らせます。
5. **水をやって休ませる**：鉢底から濁りのない水が流れ出るまで、たっぷり水を与えます。

剪定の基本と、忌み枝の見分け方は[盆栽の剪定・芽摘み・針金かけ](/guides/article-7)で、図とあわせて説明しています。植え付けの手順は[盆栽の植え替え](/guides/article-16)も参考になります。

> **ポイント** 根を切ったぶん、枝葉も減らすと、根と葉のつり合いがとれて樹が弱りにくくなります。根を多く切ったときは、枝も少し多めに整理します。

### 針金をかけるのは、根が落ち着いてから

枝の向きを変える針金かけは、樹に負担のかかる作業です。根を切って植え付けたばかりの樹に、強い針金かけを同じ日に重ねるのは避けます。植え付けた年は樹を休ませ、新芽が伸びて元気を取り戻してから、少しずつ針金で枝の向きを整えていきます。

針金の太さの選び方や、かける・外す時期は[盆栽の針金の選び方](/guides/bonsai-wire-guide)にまとめています。

## 作ったあとの管理

植え付けたばかりの樹は、根が少なくなっています。次のように、根が回復するまで休ませます。

- **最初の2週間**：直射日光と強い風を避け、明るい日陰に置きます。
- **水やり**：土の表面が乾いたら、鉢底から流れ出るまで与えます。小さな鉢は乾きやすいので、毎日様子を見ます。
- **肥料**：植え付け直後は与えません。新しい芽が伸び始めてから、少量の置き肥から始めます。
- **その後**：新芽が動き出したら、少しずつ日の当たる場所に移します。多くの盆栽は、日当たりと風通しのよい屋外で育てます。

届いた盆栽の世話の流れは[はじめての1か月](/hajimete)でも、チェックリストで確かめられます。

### 作ってから1年の流れ

| 時期 | すること |
|---|---|
| 早春（作業の日） | 正面を決め、枝を整理して鉢に植える |
| 春〜初夏 | 明るい日陰から日なたへ。新芽が伸びたら置き肥を始める |
| 初夏〜夏 | 伸びすぎた枝を軽く切る。夏は水切れに注意 |
| 秋 | 置き肥。樹の元気を見て、針金で枝の向きを整え始める |
| 冬 | 落葉樹は枝ぶりを眺めて、次の春に切る枝を考える。寒さ対策をする |

月ごとの作業は[今月の手入れ](/teire)で、樹の種類ごとに確かめられます。

## 樹形を決めるときの参考に

盆栽には、まっすぐ立つ「直幹（ちょっかん）」、幹が曲がりながら立つ「模様木（もようぎ）」、鉢の縁より下に垂れる「懸崖（けんがい）」などの樹形があります。苗木の幹の動きに合った樹形を選ぶと、無理なく形を作れます。

樹形の名前と特徴は[名前・樹形図鑑](/zukan)で、図とあわせて調べられます。細い苗木を何本か集めて林の景色を作る方法は、[盆栽の寄せ植えの作り方](/guides/bonsai-forest-planting)で紹介しています。

## 教室で教わる・素材を探す

最初の作業を誰かに見てもらいたいときは、盆栽教室で教わるのも近道です。持ち込んだ苗木の手入れを教えてくれる教室もあります。[盆栽体験・盆栽教室を探す](/taiken)で、地域や内容から探せます。

小さな苗から育てる栽培キットや、手頃な価格の若い樹は、[家で始める盆栽キット](/taiken#ie-de)や[3,000円以下の盆栽](/selection/bonsai-under-3000)から選べます。

## よくある質問

### ホームセンターの庭木の苗でも盆栽になりますか？

なります。盆栽向けとして売られていなくても、根張りがよく、下のほうに枝のある苗木なら素材になります。ただし、もともと大きく育つ樹は、葉や花も大きいままなので、小さな鉢では姿のつり合いがとりにくいことがあります。

### 何年くらいで盆栽らしくなりますか？

樹種や苗木の大きさによって違いますが、枝ぶりが整い、盆栽らしく見えるまでには数年かかるのが一般的です。毎年の剪定と植え替えで、少しずつ形を作っていきます。

### 最初から小さな鉢に植えてもいいですか？

根を一度に大きく切って小さな鉢に入れると、樹が弱ることがあります。最初はひと回り大きめの鉢に植え、樹が元気に育っているのを確かめながら、植え替えのたびに鉢を小さくしていくと安心です。

### 枝を切りすぎてしまったら？

切った枝は戻せませんが、多くの樹は元気なら新しい芽を出します。日当たりのよい場所で育て、水切れさせないように世話を続けます。次からは、迷った枝はすぐに切らず、一度残しておく習慣をつけます。

盆栽は海外でも「bonsai」のまま通じる言葉です。英語の本や動画、海外の展示会では、樹形や作業の名前にも日本語がそのまま使われることがよくあります。

一方で、幹や枝、植え替えといった基本の言葉は英語で言うことが多く、両方を知っておくと会話がぐっと楽になります。ここでは、よく使う言い方を場面ごとにまとめます。

## 英語でもそのまま使われる日本語

まず、日本語のまま通じることが多い言葉です。英語の文の中に混ぜて使われます。

| 日本語 | 英語での書き方 | 意味 |
|---|---|---|
| 盆栽 | bonsai | 単数も複数も同じ形で、bonsais とはあまり言わない |
| 根張り | nebari | 幹の根元から四方に広がる根の見え方 |
| ジン | jin | 枝の皮をはいで白く枯らし、見どころにしたもの |
| シャリ | shari | 幹の一部の皮をはいで枯らした部分 |
| 寄せ植え | yose-ue | 複数の樹を一つの鉢に植え、林や森に見立てたもの |
| 小品・豆 | shohin / mame | 小さな盆栽。大きさの区切りは団体や展示会によって違う |
| 苔玉 | kokedama | 根を土で丸めて苔で包んだもの |

発音はローマ字読みに近く、「ネバリ」「ショーヒン」と言えばたいてい伝わります。

## 樹の部位の言い方

樹の部位は英語で言うのが一般的です。図の6つを覚えておくと、写真を見ながらの相談がしやすくなります。

![盆栽の部位の英語と日本語。Apexは頭、Foliage padは枝葉の塊、Branchは枝、Trunkは幹、Nebariは根張り、Potは鉢](/images/articles/diagrams/bonsai-english-terminology-guide-parts.svg)
*図：盆栽の部位の英語と日本語*

- **apex（頭）**：樹のいちばん上の部分。「The apex is too strong.（頭が強すぎる）」のように使います。
- **foliage pad（枝葉の塊）**：枝の先に雲のようにまとまった葉の部分。日本語の「枝棚」に近い意味です。
- **branch（枝）**：1の枝・2の枝は first branch、second branch と言います。
- **trunk（幹）**：幹の太り方は taper（下から上へ細くなる流れ）という言葉で表します。
- **nebari（根張り）**：英語でも nebari のまま。root flare と言うこともあります。
- **pot（鉢）**：鉢の向きや正面は front と言います。

## 代表的な樹形の英語

樹形は英語の名前と日本語の名前が併記されることが多く、どちらでも通じます。

![代表的な樹形の英語と日本語。Formal uprightは直幹、Informal uprightは模様木、Slantingは斜幹、Cascadeは懸崖、Literatiは文人木、Forestは寄せ植え](/images/articles/diagrams/bonsai-english-terminology-guide-styles.svg)
*図：代表的な6つの樹形の英語*

| 日本語 | 英語 | 形の特徴 |
|---|---|---|
| 直幹（ちょっかん） | formal upright | 幹がまっすぐ上に立つ |
| 模様木（もようぎ） | informal upright | 幹が左右に曲がりながら上に伸びる |
| 斜幹（しゃかん） | slanting | 幹が斜めに傾いて立つ |
| 懸崖（けんがい） | cascade | 幹や枝が鉢の縁より下へ垂れ下がる |
| 半懸崖（はんけんがい） | semi-cascade | 鉢の縁の高さあたりまで垂れる |
| 文人木（ぶんじんぎ） | literati | 細い幹に、少ない枝と葉で軽やかに仕立てる |
| 箒立ち（ほうきだち） | broom | 幹の上から枝が箒のように広がる。欅に多い |
| 吹き流し（ふきながし） | windswept | 枝が一方向に流れ、強い風を受けた姿を表す |
| 双幹（そうかん） | twin trunk | 根元から2本の幹が立つ |
| 株立ち（かぶだち） | clump / multi-trunk | 根元から3本以上の幹が立つ |
| 石付き（いしつき） | root over rock / rock planting | 石に根をからませたり、石の上に植えたりする |
| 寄せ植え（よせうえ） | forest / group planting | 複数の樹で林の景色をつくる |

## 手入れの作業の言い方

作業の名前は英語で言うのが一般的です。

| 日本語 | 英語 |
|---|---|
| 水やり | watering |
| 肥料をやる | fertilizing / feeding |
| 剪定 | pruning |
| 芽摘み | pinching |
| 芽切り | candle cutting（松の場合） |
| 葉刈り | defoliation / leaf cutting |
| 針金かけ | wiring |
| 植え替え | repotting |
| 根を切る | root pruning |
| 樹形をつくる | styling |
| 山から採った素材 | yamadori |

「松の芽切り」のように、樹種によって作業の言い方が変わるものもあります。作業そのものの手順は、[盆栽の剪定・芽摘み・針金かけ入門](/guides/article-7)で説明しています。

> **ポイント** 季節は「in early spring（早春に）」「after the leaves harden off（葉が固まってから）」のように、月より生育の段階で言うことが多いです。国によって季節の時期がずれるためです。

## 土と道具の言い方

土や道具の名前にも、日本語がそのまま使われているものがあります。海外の通販サイトや動画でもよく目にする言葉です。

| 日本語 | 英語での言い方 | 補足 |
|---|---|---|
| 赤玉土 | akadama | 日本の盆栽用の土として、そのまま通じることが多い |
| 鹿沼土 | kanuma | さつきなどに使われる土 |
| 軽石 | pumice | 水はけをよくするために混ぜる |
| 又枝切り | concave cutter | 枝を付け根から切り、切り口をくぼませる |
| 針金切り | wire cutter | 針金を外すときに使う |
| 根かき | root hook / root rake | 植え替えのときに根をほぐす |
| 回転台 | turntable | 鉢をのせて回しながら作業する台 |
| 卓 | stand / display table | 展示や飾りに使う台 |

## 手入れのメモに使える短い文

盆栽を贈るときや、預けるときに添える手入れのメモには、次のような短い文が使えます。

- Keep it outdoors in a sunny spot.（日当たりのよい屋外に置いてください）
- Water when the soil surface is dry, until water runs out of the bottom.（土の表面が乾いたら、鉢底から流れ出るまで水をやってください）
- Avoid strong afternoon sun in summer.（夏は午後の強い日差しを避けてください）
- Protect from frost in winter.（冬は霜に当てないでください）
- Do not keep it indoors for more than a few days.（室内に置くのは数日までにしてください）

> **注意** 樹種名は、英語の一般名と学名を併記すると確実です。たとえば黒松は Japanese black pine（Pinus thunbergii）、もみじは Japanese maple（Acer palmatum）です。一般名は国や地域で違うことがあります。

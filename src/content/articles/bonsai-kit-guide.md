盆栽キット（栽培セット）は、鉢・土・種や苗など、盆栽を始めるのに必要な物を一つの箱にまとめたものです。何をそろえればよいか分からない方でも、届いたその日から始められます。

キットには、大きく分けて **種から育てるキット** と **苗から仕立てるキット** の2つがあります。芽が出る瞬間から楽しみたいなら種から、すぐに盆栽らしい姿を楽しみたいなら苗からを選びます。

## 種から育てるか、苗から仕立てるか

| | 種から育てるキット | 苗から仕立てるキット |
|---|---|---|
| 楽しみ | 芽が出て育っていく過程 | 剪定や針金で形を作っていく過程 |
| 盆栽らしい姿になるまで | 数年かかる | 届いたときから樹の形がある |
| 価格 | 比較的手ごろ | 苗の分だけ高めになる |
| 向く人 | 時間をかけて育てたい人、子どもと一緒に | すぐに盆栽を楽しみたい人 |


**種から育てるキット** は、黒松やもみじ、桜などの種が入っていることが多く、芽が出てから盆栽らしい姿になるまでには数年かかります。そのぶん、自分で育てた樹への愛着はひとしおです。

**苗から仕立てるキット** は、すでにある程度育った苗木に、鉢や土、針金などが付いています。届いたらすぐに植え付けて、剪定や針金かけで形を作る楽しみがあります。

### キットによくある樹の種類

| 樹の種類 | 特徴 |
|---|---|
| 黒松 | 種から育てるキットの定番。比較的芽が出やすく、一年中緑の葉を楽しめる |
| もみじ | 秋の紅葉が楽しめる。種は、寒さに当てる準備が必要なことが多い |
| 桜 | 花を楽しめるが、花が咲くまでには年数がかかる。種の準備が必要なことが多い |
| 真柏・五葉松など | 苗から仕立てるキットに多い。針金で形を作る練習に向く |

どの樹が入っているかで、置き場所や世話の仕方が変わります。キットを選ぶときは、育てたい樹の育て方もあわせて調べておくと安心です。

## セットに入っている物と、別に用意したい物

多くのキットには、次の物が入っています。

- 鉢（鉢底網が付いていることも多い）
- 土（盆栽向けの用土）
- 種または苗
- 育て方の説明書

一方で、次の物は入っていないことがあるので、商品ページで確かめます。

- **剪定ばさみ**：苗の枝を整えるときに必要です。
- **じょうろ**：細かい水が出る、注ぎ口の細いものが使いやすいです。
- **受け皿**：室内や玄関先に飾るときに使います。
- **霧吹き**：種まき直後の、土を流したくない時期の水やりに便利です。

### キットを選ぶときに確かめること

- **入っている樹の種類**：育てたい樹か、自分の住まいで育てられる樹かを確かめます。
- **始める時期に合っているか**：種には、まくのに向く季節があります。届いてすぐにまけない時期なら、説明書の保存方法を確かめます。
- **鉢に水抜き穴があるか**：見た目重視の器の中には、穴がないものもあります。
- **説明書の内容**：種の準備や、芽が出たあとの育て方まで書かれていると安心です。
- **置き場所**：多くの樹は屋外で育てる前提です。室内だけで育てたいときは、その旨が書かれたキットを選びます。

## 始めるのに向く時期

種から育てる場合は、**春（3〜4月ごろ）** に種をまくものが多くあります。暖かくなって芽が出やすく、そのあとの成長の季節を長く取れるためです。秋にまく種類もあるので、説明書の時期を確かめます。

苗から仕立てるキットは、植え付けや植え替えに向く **春か秋** に始めると、根を傷めにくくなります。真夏と真冬は、植物の負担が大きいので避けます。

## 種まきから発芽後の育て方

### 種まきの手順

手順は樹の種類やキットによって異なるので、説明書がある場合はそちらを優先します。一般的には、次のような流れです。

1. **種の準備**：種類によっては、ひと晩ほど水に浸けて吸水させたり、湿らせた状態で冷蔵庫に入れて一定期間冷やしたりします。もみじや桜など、冬の寒さを経てから芽を出す性質の樹で行われることが多い準備です。
2. **土を湿らせる**：鉢に土を入れ、あらかじめ水を含ませておきます。
3. **種をまく**：種どうしが重ならないよう、間をあけて置きます。
4. **土をかける**：種が隠れる程度に薄く土をかけます。厚くかけすぎると芽が出にくくなります。
5. **乾かさずに待つ**：明るい日陰に置き、土の表面が乾かないよう霧吹きなどで湿らせます。

### 発芽後の育て方

芽が出たら、少しずつ日に当てる時間を増やします。ずっと日陰に置いたままだと、ひょろひょろと弱い苗になります。

芽がたくさん出て混み合ってきたら、元気なものを残して間引きます。肥料は、本葉が開いてしっかりしてきてから、薄いものを少しずつ与えます。

### 盆栽らしい姿になるまでの目安

育ち方は樹の種類や環境で大きく変わるので、おおよその流れとして考えます。

| 時期 | すること |
|---|---|
| まいてから数週間〜数か月 | 発芽。種類によって早さに大きな差がある |
| 1年目 | 苗を枯らさずに育てる。冬越しをさせる |
| 2〜3年目 | 1本ずつ鉢に植え替え、幹を太らせる |
| 3〜5年目以降 | 剪定や針金かけで、少しずつ形を作っていく |

> **ポイント** 種から育てる盆栽は、何年もかけて楽しむものです。毎年同じ時期に写真を撮っておくと、成長がよく分かります。

### 1年目の季節ごとの世話

| 季節 | 世話のポイント |
|---|---|
| 春 | 種まきと発芽。土を乾かさず、芽が出たら少しずつ日に当てる |
| 夏 | 小さな苗は乾きやすく、強い日差しにも弱い。午後の日差しを避け、水切れに注意する |
| 秋 | 苗がしっかりしてくる時期。日当たりのよい場所で、冬に備えて丈夫に育てる |
| 冬 | 霜や凍結、冷たい風の当たらない軒下などで冬越しさせる。水やりは控えめに続ける |

1年目の苗は小さく根も浅いため、真夏の水切れと冬の凍結がいちばんの心配です。この2つを乗り越えると、2年目からはぐっと育てやすくなります。

> **注意** 寒さに当てることで春に芽吹く樹もあります。冬のあいだずっと暖かい室内に入れておくのではなく、凍らない程度の屋外で冬越しさせるのが基本です。

## 発芽させるときによくある失敗

- **土を乾かしてしまう**：芽が出るまでは、土の表面を乾かさないようにします。乾くと芽が出にくくなります。
- **水のやりすぎで種が流れる**：じょうろで勢いよく水をかけると、種が流れたり土が掘れたりします。最初は霧吹きや、鉢ごと浅く水につける方法が向いています。
- **すぐに諦める**：種類によっては、芽が出るまでに数週間以上かかることがあります。説明書の日数を目安に待ちます。

種類によっては、まく前に水に浸けたり、冷やしたりする準備が必要なことがあります。説明書の手順どおりに進めるのがいちばんの近道です。

### 芽が出たあとのトラブル

- **ひょろひょろと細長く伸びる（徒長）**：光が足りないことが主な原因です。室内の窓辺でも光が不足しがちなので、明るい屋外の日なたへ少しずつ慣らします。
- **土の表面に白いカビが出る**：湿ったまま風が通らないと出やすくなります。風通しのよい場所に移し、水やりは表面が乾き始めてからにします。
- **苗が根元から細くなって倒れる**：蒸れや過湿で、根元が傷んだときに起こります。倒れた苗は元に戻りにくいので取り除き、残った苗は風通しをよくして水を控えめにします。

### よくある質問

- **室内だけで育てられる？**：多くの樹は、日光と季節の変化が必要な屋外向きの植物です。室内では光が足りず、徒長しやすくなります。飾るときだけ室内に入れ、普段は屋外で育てるのが基本です。
- **種が余ったら？**：説明書に保存方法があれば、それに従います。種は時間がたつと芽が出にくくなることが多いので、なるべく早めにまくのがおすすめです。
- **芽が少ししか出なかった**：種から育てる場合、まいた種がすべて芽を出すとは限りません。出た芽を大切に育てれば十分です。
- **いつ別の鉢に植え替える？**：混み合った苗を1本ずつに分けるのは、多くの場合、芽が動き出す前の春が向いています。根が細く傷みやすいので、土ごとそっと分けます。

## 苗から仕立てるキットの始め方

苗から仕立てるキットは、届いたら箱から出し、まずは明るい日陰で苗を休ませます。植え付けるときは、鉢底網を付けた鉢に土を入れ、苗の根を軽くほぐして植えます。

植え付けたあとは、鉢底から流れ出るまでたっぷり水を与え、1〜2週間は強い日差しと風を避けて様子を見ます。新しい芽が動き出したら、日当たりのよい場所へ移します。剪定や針金かけは、苗が新しい鉢になじんでから始めます。

剪定や針金かけに向く時期は、樹の種類によって異なります。一度にたくさんの枝を切ったり、急に強く曲げたりすると苗が弱るので、最初は伸びすぎた枝を整える程度から始めます。キットに付いている針金は、細い枝向けのものが多いので、太い幹を曲げるのには向きません。

> **ポイント** 植え付けの前に、苗をいろいろな方向から眺めて、いちばん見栄えのする面（正面）を決めておくと、植える向きや、あとで切る枝を決めやすくなります。
